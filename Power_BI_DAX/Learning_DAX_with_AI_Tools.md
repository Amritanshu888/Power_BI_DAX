# Using AI Tools to Learn DAX in Power BI

## 1. Introduction

In the previous sessions, different types of **DAX (Data Analysis Expressions) functions** were learned manually through examples and use cases.

This session introduces another approach:

> **Using AI tools to learn and practice DAX functions.**

AI tools such as:

* Perplexity
* ChatGPT
* Grok
* Other AI assistants

can help you:

* Generate DAX expressions
* Create sample datasets
* Understand different DAX functions
* Generate additional examples
* Explore different business scenarios
* Troubleshoot DAX errors
* Learn alternative ways of writing expressions

The key idea is that instead of only learning predefined examples, you can **ask an AI tool to generate new scenarios and expressions for practice.**

---

# 2. Important Principle: AI Does Not Replace BI Fundamentals

Although AI tools can save a lot of time, you should **not depend completely on them**.

You still need a strong understanding of:

* Power BI fundamentals
* DAX fundamentals
* Data modeling
* Tables and columns
* Measures
* Calculated columns
* Functions and their behavior
* Filter context
* Evaluation concepts

### Why?

If you understand the fundamentals, you can:

1. Write better prompts.
2. Understand the AI-generated DAX.
3. Identify whether the generated expression is correct.
4. Decide which suggestions are actually useful.
5. Debug incorrect expressions.
6. Modify the generated expression according to your requirement.

### Important takeaway

> **AI is a productivity and learning tool, not a replacement for fundamental BI knowledge.**

You should not blindly use everything suggested by an AI tool.

# 5. Creating the Table in Power BI Desktop

Once the DAX expression is generated by the AI, it can be copied into Power BI Desktop.

### Steps

### Step 4: Paste the AI-generated DAX

**Ctrl + A → Ctrl + V**

# 11. Asking AI to Generate Full Month Names

Instead of manually figuring out the formatting argument, the instructor goes back to Perplexity.

The new requirement is:

> I want a DAX expression that helps me extract the full month name.

The AI explains that the formatting expression needs to use four `M` characters rather than three.

The relevant formatting concept is:

```DAX
"MMMM"
```

rather than:

```DAX
"MMM"
```

### Difference

| Format | Result                   |
| ------ | ------------------------ |
| `MMM`  | Jan, Feb, Mar            |
| `MMMM` | January, February, March |

# 18. Overall Learning Workflow Demonstrated

The complete workflow demonstrated in the lecture is:

### Step 1 — Learn DAX fundamentals

First learn DAX manually through:

* Lectures
* Documentation
* Examples
* Practice exercises

### Step 2 — Open an AI tool

You can use:

* Perplexity
* ChatGPT
* Grok
* Other AI tools

### Step 3 — Describe your requirement

For example:

> "Give me a DAX expression to extract the month name from a date column."

### Step 4 — Review the AI response

Do **not** blindly copy everything.

Understand:

* What function is being used?
* What arguments are required?
* What output will it produce?
* Is it appropriate for your requirement?

### Step 5 — Copy the DAX expression

Copy the relevant expression from the AI tool.

### Step 6 — Implement it in Power BI

Depending on the requirement, create:

* New Table
* New Column
* New Measure

### Step 7 — Verify the output

Check whether the generated result matches the expected output.

### Step 8 — Iterate

If the result isn't exactly what you want, go back to the AI tool and refine your prompt.

You should determine:

* Is it appropriate for your data model?
* Does it produce the desired result?

# 21. Importance of Good Prompt Writing

The quality of the AI response depends significantly on the prompt.

Instead of asking:

> "Give me DAX."

provide context.

For example:

> "I have a table called 'Calendar Table' with a Date column. Give me a DAX calculated column that extracts the full month name from the Date column."

This gives the AI:

* Table name
* Column name
* Desired output
* Type of DAX requirement

and therefore makes the response more useful.

# 23. AI for DAX Error Troubleshooting

Another important use case discussed is **debugging DAX**.

If you encounter an error while creating:

* A calculated column
* A calculated table
* A measure
* A DAX expression

you can provide the error and relevant code to an AI tool.

For example:

```text
Here is my DAX expression:
<your DAX>

I am getting this error:
<error message>

Explain why this error is occurring and provide the corrected expression.
```

AI can then help you:

1. Understand the error.
2. Identify the problematic part.
3. Correct the expression.
4. Explain the corrected expression.
5. Suggest alternative approaches where appropriate.

Don't blindly trust the generated DAX.

**Learn → Practice → Ask AI → Implement → Validate → Iterate**
